## Security Policy

### Scope

This repository contains deterministic Brazilian financial mathematics for Python. It is a research library and not a production custody, execution, accounting, or investment-advice system.

### Reporting a vulnerability

Please do not open a public issue for a suspected security problem. Contact @thayroncarlessi through GitHub with a private description, reproduction steps, affected commit, and impact assessment. Do not include client data, credentials, tokens, or other secrets.

### Data and credentials

Never commit client information, market credentials, API tokens, private keys, OAuth files, local databases, or unredacted reports. Use synthetic fixtures for tests and examples.

### Responsible disclosure

The maintainer will acknowledge, validate, and coordinate a fix or mitigation before public disclosure. Changes to calendars, day-count conventions, rates, pricing, or valuation logic require tests and independent review.
